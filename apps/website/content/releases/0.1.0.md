The first published version of `@qino/cms`, the core library and `qino` CLI.

## Highlights

- `createQino` with `defineCollection`, `defineTree`, and `defineItem`.
- Standard Schema validation with the Markdown body supplied as `markdown`.
- Relations between any primitives, resolved to a configurable depth.
- Named views with `resolveRelations`, `augment`, and collection-only `filter` and `sort`.
- `qino lint`, `qino check`, and `qino build`, with generated slug types.
- `getMarkdownStats` from `@qino/cms/utils`.
