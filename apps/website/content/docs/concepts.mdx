---
title: Concepts
description: The mental model behind collections, trees, items, schemas, relations, views, and types.
---

qino has three primitives, one per shape of content: a [collection](/docs/concepts/collections) for many entries of the same kind, a [tree](/docs/concepts/trees) for ordered, nested pages, and an [item](/docs/concepts/items) for a single file. Each validates its entries with a [schema](/docs/concepts/schemas). The pages after them explain how entries reference each other, how views reshape them, and the order in which qino reads, validates and types them. Read them before the [API reference](/docs/api) to know what each option is for.
