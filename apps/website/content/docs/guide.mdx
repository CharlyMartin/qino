The guide takes a project from installing qino to building with it. Start with [Installation](/docs/guide/installation), which adds `@qino/cms` and a first collection, then [Project structure](/docs/guide/project-structure) and [Content folder](/docs/guide/content-folder), which show where definitions and content files live. The pages after them cover frontmatter, the `qino` CLI, content for AI agents and the cloud UI. [Philosophy](/docs/guide/philosophy) explains what qino leaves out, and why.
