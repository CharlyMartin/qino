---
title: defineTree
description: Define hierarchical, ordered content backed by nested folders.

---

Defines a tree: a nested directory where every node is a file and sections are a file plus a same-named folder. Returns getters for structure, content, and navigation.

```ts title="qino/trees/docs.ts"
import { z } from "zod";

import qino from "../";

export const docsTree = qino.defineTree({
  directory: "docs",
  extension: ".md",
  titleField: "title",
  schema: z.object({
    title: z.string(),
  }),
});
```

## Signature

```ts title="@qino/cms"
qino.defineTree(params: {
  directory: `/${string}`;
  extension: ".md" | ".mdx" | ".markdown" | ".json";
  schema: StandardSchemaV1<unknown, Record<string, unknown>>;
  titleField: StringKeyOfSchemaOutput;
  orderFileName?: string;
  relations?: Record<RelationPath, Primitive | (() => Primitive)>;
  media?: Record<StringPath, { accepted: MimeType; maxSize: Size }> & { markdown?: Array<{ accepted: MimeType; maxSize: Size }> };
  markdownStats?: boolean;
  views?: (view: ViewHelper) => Record<string, View> & { default: View };
  cloud?: { displayAs?: string; displayEntryAs?: `${string}{${RequiredField}}${string}`; saveEntryAs?: `${string}{${RequiredField}}${string}`; searchableBy?: Array<Field>; hiddenFields?: Array<OptionalField>; media?: { saveFileAs?: string } };
}): Tree;
```

## Parameters

| Name            | Type                                                                                  | Required | Default         | Description                                                                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------- | -------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `directory`     | `` `/${string}` ``                                                                    | yes      |                 | Directory under `contentFolder`. Walked recursively. Owned exclusively by this tree                                                                                                                                             |
| `extension`     | `".md" \| ".mdx" \| ".markdown" \| ".json"`                                           | yes      |                 | Only files with this extension are nodes                                                                                                                                                                                        |
| `schema`        | Standard Schema object validator                                                      | yes      |                 | Synchronous. May not declare `_meta`, nor `markdown`/`raw`/`_stats` for Markdown                                                                                                                                                |
| `titleField`    | key of schema output                                                                  | yes      |                 | Field whose string value titles each node. Non-string keys are a type error                                                                                                                                                     |
| `orderFileName` | `string`                                                                              | no       | `"_order.json"` | Per-folder ordering file                                                                                                                                                                                                        |
| `relations`     | `Record<path, primitive \| () => primitive>`                                          | no       | `{}`            | Same grammar as collections                                                                                                                                                                                                     |
| `media`         | `Record<path, { accepted; maxSize }> & { markdown? }`                                 | no       | `{}`            | Media fields, keyed by path to a string field, with the one MIME type each accepts and its max size. Image fields are read as `QinoImage`. `markdown` lists the rules body images must match. See [Media](/docs/concepts/media) |
| `markdownStats` | `boolean`                                                                             | no       | `false`         | Adds `_stats`, the word and character counts of the body. Markdown and MDX only. See [MarkdownStats](/docs/api/types/markdown-stats)                                                                                            |
| `views`         | `(view) => { default: View; [name]: View }`                                           | no       |                 | Helper offers `resolveRelations` and `augment` only. `filter` and `sort` are rejected                                                                                                                                           |
| `cloud`         | `{ displayAs?; displayEntryAs?; saveEntryAs?; searchableBy?; hiddenFields?; media? }` | no       |                 | Cloud UI names, entry labels (default: `titleField`) and naming, search, hidden fields, and where uploads are saved. Requires `cloud` on `initQino`. See [Cloud](/docs/guide/cloud#primitives)                                  |

## Throws

At definition time, the shared view errors listed on [defineCollection](/docs/api/collection), plus:

- `tree views do not support filter or sort.`
- `tree view "<name>" does not support filter or sort.`
- `"<id>" sets \`cloud\`, but initQino doesn't. Add \`cloud\` to initQino.`

Layout errors surface when a getter walks the tree. See [getTree](/docs/api/tree/get-tree).
