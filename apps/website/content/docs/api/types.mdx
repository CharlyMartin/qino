`@qino/cms` exports these types:

| Type                                                                                              | Purpose                                                               |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| [`Infer`](/docs/api/types/infer)                                                                  | Entry types of a primitive, per view                                  |
| [`Collection`, `Tree`, `Item`](/docs/api/types/primitives)                                        | Return types of the three define functions                            |
| [`CollectionEntryMeta`, `TreeEntryMeta`, `ItemEntryMeta`, `AnyEntry`](/docs/api/types/entry-meta) | The `_meta` shapes and the loosest entry type                         |
| [`TreeNode`](/docs/api/types/tree-node)                                                           | Structural node returned by tree getters                              |
| [`QinoSlugRegistry`](/docs/api/types/slug-registry)                                               | Interface augmented by generated slug types                           |
| [`MarkdownStats`](/docs/api/types/markdown-stats)                                                 | The `_stats` field added by `markdown.stats`                          |
| [`MarkdownToc`](/docs/api/types/markdown-toc)                                                     | The `_toc` field added by `markdown.toc`                              |
| [`MediaRule`, `MediaSize`, `MediaParse`, `MediaParseContext`](/docs/concepts/media)               | A `media` or `markdown.media` rule, to share rules between primitives |
| [`MarkdownConfig`](/docs/api/collection#parameters)                                               | The `markdown` option                                                 |

Other option shapes, such as the config passed to `initQino`, the relation depth, or getter options are not exported. They are documented inline on the function pages.
