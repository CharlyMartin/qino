Defines a collection: a flat directory of files with one extension and one schema. Returns getters for listing, reading, and enumerating slugs.

```ts title="qino/collections/posts.ts"
import { z } from "zod";

import qino from "../";
import { authorCollection } from "./authors";

export const postCollection = qino.defineCollection({
  directory: "posts",
  extension: ".md",
  schema: z.object({
    title: z.string(),
    author: z.string(),
    draft: z.boolean(),
  }),
  relations: { author: authorCollection },
  views: (view) => ({
    default: view({ filter: (post) => !post.draft }),
    detail: view({ resolveDepth: { author: 2 } }),
  }),
});
```

## Signature

```ts title="@qino/cms"
qino.defineCollection(params: {
  directory: `/${string}`;
  extension: ".md" | ".mdx" | ".markdown" | ".json";
  schema: StandardSchemaV1<unknown, Record<string, unknown>>;
  relations?: Record<RelationPath, Primitive | (() => Primitive)>;
  media?: Record<StringPath, MediaRule>;
  markdown?: {
    stats?: boolean;
    toc?: boolean | { upTo?: "h1" | "h2" | "h3" | "h4" | "h5" | "h6"; slug?: (text: string) => string };
    media?: MediaRule | Array<MediaRule>;
  };
  views?: (view: ViewHelper) => Record<string, View> & { default: View };
  cloud?: { displayAs?: string; displayEntryAs?: `${string}{${RequiredField}}${string}`; saveEntryAs?: `${string}{${RequiredField}}${string}`; searchableBy?: Array<Field>; sortableBy?: Array<ScalarField>; hiddenFields?: Array<OptionalField>; media?: { saveFileAs?: string } };
}): Collection;

type MediaRule = { accepted: MimeType; maxSize: Size; parse?: (value: string, ctx: MediaParseContext) => string | undefined };
```

## Parameters

| Name        | Type                                                                                               | Required | Default | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | -------------------------------------------------------------------------------------------------- | -------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `directory` | `` `/${string}` ``                                                                                 | yes      |         | Directory under `contentFolder`. Must start with `/`. Flat: nested files are ignored                                                                                                                                                                                                                                                                                                                                                                                                |
| `extension` | `".md" \| ".mdx" \| ".markdown" \| ".json"`                                                        | yes      |         | Only files with this extension are entries                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `schema`    | Standard Schema object validator                                                                   | yes      |         | Synchronous. Receives frontmatter, or the JSON object. May not declare `_meta`, nor `markdown`/`raw`/`_stats`/`_toc` for Markdown                                                                                                                                                                                                                                                                                                                                                   |
| `relations` | `Record<path, primitive \| () => primitive>`                                                       | no       | `{}`    | JSON paths into the schema output mapped to target primitives. `[*]` marks an array hop                                                                                                                                                                                                                                                                                                                                                                                             |
| `media`     | `Record<path, MediaRule>`                                                                          | no       | `{}`    | Media fields, keyed by path to a string field, with the one MIME type each accepts and its max size. Image fields are read as `QinoImage`, and `parse` reads a value first. See [Media](/docs/concepts/media)                                                                                                                                                                                                                                                                       |
| `markdown`  | `{ stats?; toc?; media? }`                                                                         | no       | `{}`    | Configures the body. Markdown and MDX only. `stats` adds `_stats`, its word and character counts. See [MarkdownStats](/docs/api/types/markdown-stats). `toc` adds `_toc`, its headings with their anchor ids: `true` lists every level, `upTo` stops at one, and `slug` sets how ids are made. See [MarkdownToc](/docs/api/types/markdown-toc). `media` lists the rules body images must match, each read with its own `parse`. See [Body images](/docs/concepts/media#body-images) |
| `views`     | `(view) => { default: View; [name]: View }`                                                        | no       |         | Factory run once at definition. Must return a `default` view made with the helper                                                                                                                                                                                                                                                                                                                                                                                                   |
| `cloud`     | `{ displayAs?; displayEntryAs?; saveEntryAs?; searchableBy?; sortableBy?; hiddenFields?; media? }` | no       |         | Cloud UI names, entry labels and naming, search, sort, hidden fields, and where uploads are saved. Requires `cloud` on `initQino`. See [Cloud](/docs/guide/cloud#primitives)                                                                                                                                                                                                                                                                                                        |

`resolveDepth`, `augment`, `filter`, and `sort` are rejected at the root. Put them inside a view. See [view](/docs/api/view).

## Returns

A `Collection` with three getters.

### Getters

- [`getEntries(options?)`](/docs/api/collection/get-entries)
- [`getEntry(slug, options?)`](/docs/api/collection/get-entry)
- [`getAllSlugs()`](/docs/api/collection/get-all-slugs)

Use `Infer<typeof postCollection>` to name the entry types. See [Infer](/docs/api/types/infer).

## Throws

At definition time:

- `Configure "<key>" inside views.default or a custom view, not at the root.`
- `Configure views with views: (view) => ({ default: view({ ... }) }). Object-form views are no longer supported.`
- `The views factory must synchronously return an object of named views.`
- `The views factory must return a "default" view created with view({ ... }).`
- `View "<name>" must be created with view({ ... }).`
- `"<id>" sets \`cloud\`, but initQino doesn't. Add \`cloud\` to initQino.`
