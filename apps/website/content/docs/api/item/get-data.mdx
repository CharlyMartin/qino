Reads the item's file, validates it, and applies the selected view.

```ts
const home = await homeItem.getData();
home.title;
home["featured-posts"][0].title; // resolved by the default view
home._meta.fileName; // "home.md"
```

## Signature

```ts
item.getData(options?: { view?: ViewName }): Promise<Entry>;
```

## Parameters

| Name           | Type      | Required | Default     | Description                |
| -------------- | --------- | -------- | ----------- | -------------------------- |
| `options.view` | view name | no       | `"default"` | A view declared in `views` |

## Returns

`Promise<Entry>`: the schema output, `_meta` (`fileName`, `filePath`, no `slug`), resolved relations at the view's depth, and the awaited augment output.

## Throws

- A raw `ENOENT` error from Node when the file does not exist.
- `Unknown view "<name>". Available views: <names>.`
- Getter option errors, validation, relation, and augment errors. See [Errors](/docs/api/errors).
