Returns the absolute URL of the item page's agent Markdown: the page's URL on `siteUrl` with `.md` appended. The item must declare [`page`](/docs/api/item#parameters).

```ts title="src/routes/about.tsx"
aboutItem.getMarkdownUrl(); // "https://example.com/about.md"
```

## Signature

```ts title="@qino/cms"
item.getMarkdownUrl(): string;
```

## Returns

`string`: `page` joined to `siteUrl`, with `.md` appended after any trailing `/`. A `page` of `/` gives `/index.md`, and `qino build` then skips writing its own `index.md`.

## Throws

- `Item "<file>" has no page: declare it to get agent Markdown and a Markdown URL.`
