title: initQino

Initializes a Qino instance bound to a content folder and a media folder. Every collection, tree, and item is defined through the returned instance.

```ts title="qino/index.ts"
import { initQino } from "@qino/cms";

const qino = initQino({
  contentFolder: "src/content",
  mediaFolder: "public",
  cli: {
    check: { localAssetReferences: { exclude: ["/og/**"] } },
  },
  cloud: {
    publish: { mode: "open_pull_request", reviewBeforePublish: true },
  },
});
```

## Signature

```ts title="@qino/cms"
function initQino(config: {
  readonly contentFolder: string;
  readonly mediaFolder: string;
  readonly cli?: {
    readonly check?: {
      readonly localAssetReferences?:
        boolean | { readonly exclude?: ReadonlyArray<string> };
    };
    readonly build?: {
      readonly types?: boolean;
    };
  };
  readonly cloud?: {
    readonly publish:
      | {
          readonly mode: "open_pull_request";
          readonly reviewBeforePublish:
            boolean | { readonly bypassIfAdmin?: boolean };
          readonly branchPrefix?: string;
        }
      | {
          readonly mode: "commit_to_default_branch";
          readonly reviewBeforePublish:
            boolean | { readonly bypassIfAdmin?: boolean };
        };
  };
}): {
  defineCollection: typeof defineCollection;
  defineTree: typeof defineTree;
  defineItem: typeof defineItem;
};
```

## Parameters

| Name                                              | Type                                                | Required | Default   | Description                                                                                                                                                                                                                                     |
| ------------------------------------------------- | --------------------------------------------------- | -------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `contentFolder`                                   | `string`                                            | yes      |           | Directory, relative to the working directory, that every `directory` and `file` path is joined onto                                                                                                                                             |
| `mediaFolder`                                     | `string`                                            | yes      |           | Directory, relative to the working directory, serving media at the site root, such as `public`                                                                                                                                                  |
| `cli.check.localAssetReferences`                  | `boolean \| { exclude? }`                           | no       | `true`    | Whether `qino check` verifies that files referenced in content exist. See [Media](/docs/guide/cli#media)                                                                                                                                        |
| `cli.check.localAssetReferences.exclude`          | `ReadonlyArray<string>`                             | no       | `[]`      | URL globs served by routes instead of `mediaFolder`, such as `/og/**`                                                                                                                                                                           |
| `cli.build.types`                                 | `boolean`                                           | no       | `true`    | Whether `qino build` writes `qino/_generated/types.d.ts`. See [qino build](/docs/guide/cli#qino-build)                                                                                                                                          |
| `cloud`                                           | `object`                                            | no       |           | Configures the cloud UI. When set, `qino build` writes `qino/_generated/config.json` and `qino check` verifies it. Requires schemas implementing [Standard JSON Schema](https://standardschema.dev/json-schema). See [Cloud](/docs/guide/cloud) |
| `cloud.publish.mode`                              | `"open_pull_request" \| "commit_to_default_branch"` | yes      |           | Whether publishing opens a pull request or commits to the default branch                                                                                                                                                                        |
| `cloud.publish.reviewBeforePublish`               | `boolean \| { bypassIfAdmin? }`                     | yes      |           | Whether an approver signs off in Qino before the author can publish. An object turns review on and configures it                                                                                                                                |
| `cloud.publish.reviewBeforePublish.bypassIfAdmin` | `boolean`                                           | no       | `false`   | Whether admins can publish before every entry is approved                                                                                                                                                                                       |
| `cloud.publish.branchPrefix`                      | `string`                                            | no       | `"qino/"` | Prefix of the branches the cloud UI opens. `open_pull_request` only                                                                                                                                                                             |

The config type is not exported; pass an object literal.

## Returns

An instance with three methods:

- [`defineCollection`](/docs/api/collection)
- [`defineTree`](/docs/api/tree)
- [`defineItem`](/docs/api/item)

The methods are closures, so destructuring them is fine:

```ts title="qino/index.ts"
export const { defineCollection, defineTree, defineItem } = initQino({
  contentFolder: "src/content",
  mediaFolder: "public",
});
```

Each instance carries a unique identity. Primitives from one instance cannot be related to primitives from another, and `qino lint` rejects a project that mixes instances.

## Throws

Nothing. Folder existence is checked by the CLI, not at creation.

## CLI expectations

The CLI loads `qino/index.ts` and requires the instance to be its default export. See [Project structure](/docs/guide/project-structure).
