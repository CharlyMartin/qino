---

```ts
import type { MarkdownStats } from "@qino/cms/utils";

type MarkdownStats = {
  wordCount: number;
  proseCharacterCount: number;
  sourceCharacterCount: number;
};
```

## Fields

| Field                  | Description                                                |
| ---------------------- | ---------------------------------------------------------- |
| `wordCount`            | Word-like segments in the extracted prose                  |
| `proseCharacterCount`  | Grapheme count of the prose after whitespace collapsing    |
| `sourceCharacterCount` | Grapheme count of the raw input, including syntax and code |

See [getMarkdownStats](/docs/api/get-markdown-stats) for what counts as prose.
