Every public function and type of `@qino/cms`, with its signature, parameters, return value, and errors. A project starts from [`initQino`](/docs/api/init-qino), then defines its content with [`defineCollection`](/docs/api/collection), [`defineTree`](/docs/api/tree), and [`defineItem`](/docs/api/item). Each define page links to the getters its primitive returns. [Errors](/docs/api/errors) lists every message qino can throw, with its cause and its fix.
